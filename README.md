### 🐾 Pô, Que Mão - Desafio de Evolução

Este projeto resolve o desafio de programação "Pô, Que Mão", onde o objetivo é determinar o **maior número de pô-que-mãos que podem evoluir** dada uma quantidade limitada de doces. É um problema clássico de otimização que foi abordado com foco em lógica fundamental.

---

## 🚀 Funcionalidades

* **Cálculo da Evolução Ótima:** Determina a quantidade máxima de pô-que-mãos que podem evoluir com os doces disponíveis.
* **Gestão de Recursos:** Simula a alocação de doces entre as criaturas, priorizando a evolução do maior número possível.
* **Processamento de Entrada/Saída:** Realiza a leitura dos dados de entrada (doces disponíveis e necessidades de cada pô-que-mão) e imprime o resultado final.

---

## ⚠️ Restrições do Desafio

Este desafio foi proposto com **restrições específicas** para a implementação do código, visando testar a capacidade de resolução de problemas de forma criativa. A solução foi desenvolvida **sem a utilização de operadores lógicos (OR, AND, NOT) e estruturas de dados do tipo Array**.

---

## 🛠️ Tecnologias

* **Java:** Linguagem de programação utilizada para o desenvolvimento da solução.

---

## 📂 Estrutura do Projeto

* O projeto consiste em um único arquivo Java que contém toda a lógica para ler as entradas, processar os dados e imprimir o resultado.

## ▶️ Como Rodar

Para executar o programa que resolve o desafio "Pô, Que Mão", siga os passos abaixo:

1.  **Compile o arquivo Java:**
    Utilize um compilador Java (como o `javac`) no seu terminal. Certifique-se de estar no diretório onde o arquivo `.java` está salvo.
    ```bash
    javac NomeDoSeuArquivo.java
    ```
2.  **Execute o programa:**
    Após a compilação bem-sucedida, execute a classe principal do programa. Ele aguardará as entradas necessárias via console.
    ```bash
    java NomeDoSeuArquivo
    ```
